# ศึกออฟฟิศ — Office Fight Night 🥊

เกมต่อยมวย 3D แบบปั่นๆ บนเว็บ (three.js) ตัวละครเป็นพนักงานร้านเปียโน ชกกันได้ทั้งในโชว์รูมและริมถนนหน้าร้าน
มุมกล้องตามหลังแบบเกม GetAmped

- 8 ตัวละคร พลังเท่ากันหมด ต่างกันแค่หน้าตา · แก้ชื่อ/ใส่รูปหน้าเพื่อนได้
- เลือกตัวแล้วเลือกต่อ: สไตล์ต่อสู้ 6 แบบ (มวยสากล ตบ เตะ มวยปล้ำ หัวร้อน เมางานเลี้ยง) + ท่าไม้ตาย 20 ท่า
- คริ คอมโบยาว และตอนโดนน็อกตัวปลิวไปแตกเป็นฝุ่น
- โหมด: ดวล 1v1 · ตะลุมบอน 4 คน · ทีม 2v2 · ไต่บันได (Arcade) · ห้องซ้อม (ลองท่ากับหุ่น ไม่จำกัดเวลา)
- ปุ่ม 📖 ดูท่าทั้งหมด: ท่าพื้นฐาน ของในร้าน และไม้ตายของทุกคน
- เล่นเครื่องเดียว 1–2 คน หรือ **ออนไลน์คนละเครื่องสูงสุด 4 คน**

- เสียงต่อยจริง เสียงพากย์ (Round 1 / Final round / Go / You win) และเฟอร์นิเจอร์ 3D ในร้าน (โซฟา ทีวี ลำโพง โต๊ะหัวหน้า…) พังได้ หยิบมาฟาดได้

**เล่นเลย:** https://mmmmoonwolf.github.io/office-fight-night — กด 🌐 เล่นออนไลน์กับเพื่อน → สร้างห้อง แล้วส่งรหัสห้องให้เพื่อน (เชื่อมต่อแบบ P2P ไม่ต้องล็อกอิน)
- แมพใหญ่: ร้านมีโซนกลอง & แอมป์ ประตูหลัง ประตูข้าง และถนนวนรอบตึก
- ร้านพังได้: กระจก กำแพง เปียโน กลอง แอมป์ — จบเกมโชว์ค่าเสียหายรวม
- อีเวนต์: ลูกค้าเข้าร้าน, ทีมยกเปียโน, ฝนตก, น้ำท่วม (+สายไฟช็อต), ไฟดับ, พายุ, รถส่งของซิ่งรอบร้าน, วินมอไซค์ทุกถนน
- หยิบของฟาด/ขว้าง, คอมโบ, จับทุ่ม, KO replay, โหมดถ่ายรูป

## เล่นบนเครื่อง

```bash
npm run dev          # http://localhost:8765/  (เล่นออฟไลน์)
                     # http://localhost:8765/mp-local.html  เปิดหลายแท็บ = ทดสอบออนไลน์ในเครื่องเดียว
```

ออนไลน์: บน GitHub Pages ใช้ P2P (PeerJS) · บน claude.ai Artifact ใช้ระบบห้องของ claude.ai

## ทดสอบ

```bash
npm install
npx playwright install chromium
npm test             # ทดสอบแบบ headless (three.js ถูก stub, ห้องออนไลน์ถูก mock)
```
